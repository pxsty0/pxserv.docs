# Veri Geçişi

**POST** `https://api.pxserv.net/database/toggleData`

Bu endpoint, belirtilen anahtarda kayıtlı değeri 0 ile 1 arasında değiştirir.

**Headers**

| Anahtar         | Değer              |
| --------------- | ------------------ |
| Content-Type    | `application/json` |
| apikey          | `Proje API Anahtarı` |
| Accept-Language | `tr` \| `en`       |

**Body**

| Anahtar | Tip    | Açıklama      |
| ------- | ------ | ------------- |
| `key`   | string | Veri anahtarı |

**Response**

#### 200

```json
{
  "status": 200,
  "message": "OK",
  "data": {}
}
```

#### Error

```json
{
  "status": 401,
  "message": "Invalid API key.",
  "data": {}
}
```
